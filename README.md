# Silicon — пакет для 1С

Окремий пакет для спеціаліста 1С: контракт HTTP API, тестовий стенд і інструкція, як бот створює контрагента і рахунок.

**Стек.** Python, FastAPI, Docker.

Паролі доступу і тестова база в публічну копію не входять.

Публічний кейс. Робоча копія з паролями і базами лишається локально і сюди не входить.
